# IT HelpDesk & Infrastructure Monitor

Портфельный проект для позиций IT Support, System Administrator и Junior Python Developer.

Сервис помогает сотрудникам создавать IT-заявки, а поддержке - вести их до решения. В следующем этапе добавим учёт устройств и мониторинг доступности инфраструктуры.

## Стек

- Python 3.12, FastAPI, SQLAlchemy
- PostgreSQL
- Docker Compose
- Swagger / OpenAPI

## Запуск

1. Установить Docker Desktop.
2. В папке проекта выполнить `docker compose up --build`.
3. Открыть `http://localhost:8000/docs`.

## Что уже реализовано

- создание и просмотр заявок;
- приоритеты и статусы заявок;
- учёт ПК, ноутбуков, принтеров и сетевых устройств;
- проверка доступности устройств по IP-адресу;
- здоровье API и подключение к PostgreSQL;
- Docker-окружение для локального запуска.

## План развития

1. Пользовательские роли: сотрудник, IT Support, администратор.
2. Мониторинг Prometheus + Grafana.
3. Документация: схема сети и регламент обработки инцидента.
